Quickstart Guide

Droplink is designed to get your gaming panels and servers connected to a professional subdomain as quickly as possible. Follow this guide to set up your first record:

  1. Login: Click the Login button on the landing page to authenticate using your Discord account.
  2. Select Domain: From the top bar inside the dashboard, select one of the available domains (e.g. droplink.gg).
  3. Add DNS Record: Click the + Add Record button. Specify your record type, name (prefix), and destination content (IP or Hostname).
  4. Save: Click save. The record is instantly pushed to Cloudflare and propagates globally in seconds.

Panel Setup Guide

Whether you're hosting on Pterodactyl, Pelican, or other game panel software, pointing your domain name is straightforward.

Pterodactyl Panel (Nginx / Web Access)

1. In the Droplink Dashboard, create a CNAME or A record pointing to your node/daemon IP. For example, create panel.yourname.droplink.gg pointing to your VPS IP.

2. Configure your Nginx virtual host config file on your VPS to recognise the new subdomain:

server_name panel.yourname.droplink.gg;

3. Generate an SSL certificate using Certbot:

certbot --nginx -d panel.yourname.droplink.gg

Pelican Panel Setup

For the modern Pelican panel, create a record using Droplink. Toggle Cloudflare proxying (orange cloud) on or off depending on whether you require raw TCP access or standard HTTPS proxying. We recommend leaving proxying enabled for panel web traffic to benefit from DDoS protection.

DNS Records Explained

Droplink supports multiple standard DNS record types to accommodate different gaming requirements:

  • A Records: Points a subdomain to an IPv4 address (e.g. 192.0.2.1). Ideal for direct server access or panel nodes.
  • AAAA Records: Points a subdomain to an IPv6 address.
  • CNAME Records: Points a subdomain to another hostname (e.g. node1.hoster.com). Ideal for virtual hosting.
  • TXT/MX Records: Used for verification and setting up custom mail services if required.

Limits & Rules

Currently, users on the Free Plan are permitted a maximum of 3 DNS records. This allows you to manage up to three distinct game panels or server addresses. If you require additional records or support for custom domains, consider joining our waitlist for the Pro plan.
